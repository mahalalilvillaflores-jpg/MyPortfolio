# Mahalalil P. Villaflores — Portfolio

Personal portfolio website and ATS-friendly resume for **Mahalalil P. Villaflores**, a BS Computer Science student at Biliran Province State University and an aspiring full-stack developer.

## Overview

- **Color Palette**: Pure Black (`#000000`), Burgundy (`#6D001A`), and Crisp White (`#FFFFFF`).
- **Animated Hero**: Centered full-screen introduction with softly blurred flowing burgundy ribbons, 3D letter-by-letter name reveal, typewriter role animation, and automatic 5-second loop.
- **About Me**: Portrait card alongside background bio, education, career goal, and personal interests.
- **Projects**: Featured showcase for **PrintDayon** and cards for **Room Management**, **Rent Tracker**, **Task Queuer**, and **Roasted Route** with interactive lightbox image previews.
- **Skills**: Categorized tech stack (**Frontend**, **Backend**, **Database**, and **Tools**) displayed as rounded-square icon cards with official SVG logos.
- **Certificates**: Verified credentials from CHED & Mapúa University and Cisco Networking Academy.
- **ATS Resume (`resume.html`)**: Clean single-column layout ready for direct printing or saving as PDF.

## Running Locally

Built with standard HTML5, CSS3, and vanilla JavaScript — no build tools or dependencies required.

1. Open `portfolio/index.html` directly in any modern browser, or
2. Use the **Live Server** extension in VS Code / Antigravity IDE (`Right-click index.html` -> `Open with Live Server`).
